## $17 和 $20 差的不是地区，是月付还是年付

官网把 Pro 标成 $17，很多中文页面直接写成“Pro 每月 $17”，这个说法只在年付时成立。

月付就是 $20/月，按月扣，12 个月共 $240。年付一次性扣 $200，摊到 12 个月是 $16.67，官方四舍五入显示 $17。**两者一年差 $40**，折扣约 17%。

年付的代价是这笔钱一次性出去，而官方帮助文档没有写明未使用月份怎么折算退款。你不确定会用满一整年，就选月付，多花的 $40 算灵活性的成本。

另外几件和价格有关的事：

- 官网价格不含适用税费，部分地区在结账时加税，部分地区显示价已含税。
- 个人档（Pro、Max、Ultra）**没有标准折扣，也没有可申请的优惠码**。官方只偶尔做限时促销，通过官方渠道发布，客服无法发放一次性折扣。
- 非营利组织的折扣只适用于 Team 和 Enterprise，Pro 用不上。
- 从 Pro 升到更高档在 Settings → Billing 里操作，按剩余账期折算差价、立即生效，实际金额看升级页显示。

## Pro 给什么，不给什么

Pro 是个人聊天产品的付费订阅，面向个人，不是团队版。团队需求应该看 Team 或 Enterprise。

付费后多出来的东西，按官方定价页和帮助文档：

- **Claude Code 访问权限**。Free 没有，这是 Pro 最值钱的一项。
- **用量提升**，按每 5 小时和每周两个窗口计算，比 Free 多得多。
- **Projects 不限数量**，Free 最多 5 个。
- **Research、Opus 模型**，Free 都没有。
- 任务交接与定时、Claude Dashboards（beta）、Claude Science、Chrome 和 Microsoft 365 里的 Claude。
- 额度用尽后可以开启 usage credits 继续用，按 API 价计费。

有一项得说清楚：**Pro 不包含 Claude Console 的 API 用量**。会员和 API 是两套分开计费的账户，想让程序调用 API，要单独开通 Console 按量付费。往 Console 里充钱不会让 claude.ai 变成 Pro，这是中文用户最常见的误解之一。

还有 Fable 这个模型：Pro 上要用 usage credits 付费才能用，Max 和 Ultra 才把它包含在订阅里（到周限额的一半）。

## 额度怎么算：两个窗口，一个池子

Pro 有两层限额同时生效：**滚动 5 小时窗口**和**每周上限**，周上限跨所有模型计算。

周上限在一个跟账号绑定的固定时间重置，跟你什么时候开始用、什么时候订阅都没关系，每个周期发完整的一份。下次重置时间在 Settings > Usage 里能看到。

具体能发多少条消息，官方没有公布数字，因为它取决于消息长度、附件大小、当前对话有多长、用的是哪个模型或功能。同一个账号，扔一份长 PDF 进去问十几个问题，和纯文字聊二十轮，消耗完全不是一回事。

**网页、桌面端、手机 App、Claude Code 共用这一份额度。** 在 Claude Code 里跑一下午，网页端的余量也会跟着掉。Claude Code 里可以用 `/usage` 看当前用量和重置时间。

官方还保留按容量追加限制的权利，比如月度上限或某些功能的单独限制，也不保证服务不中断。

### 撞到上限了怎么办

三个选择，按代价从低到高：

1. **等重置。** 提示里会写清楚什么时候恢复。
2. **开 usage credits。** 在 Settings → Usage 里开启，到上限后请求自动转成按量付费，按标准 API 价计费。可以设每月花费上限、预充金额、自动充值和提醒，费用和订阅费分开出账。Claude Code 里对应 `/usage-credits`。手机 App 订阅的只能在网页版开启，并且要先绑卡。Max 和 Ultra 自带的每月 API credits 不能拿来抵这项费用。
3. **升档。** Max 是每 5 小时和每周各 5 倍 Pro 用量，Ultra 是每周 10 倍 Pro 用量，且已验证账户没有 5 小时限制。

另外还有一个 limit reset 机制，能把 5 小时会话限额或周限额重置回满额。

**什么时候该升档**：一周里多次撞到周上限，或者每天要连续跑几小时 Claude Code，Pro 就不够用了，看 Max。偶尔撞一次 5 小时窗口、等两小时就恢复的，Pro 加 usage credits 比升档便宜。Ultra 适合那些 5 小时窗口反复打断工作流的人，$200/月对个人用户是笔不小的开支，撞不到这个程度就别上。

## 国内能不能订、怎么付

这是“能不能买”的前置条件，比选哪档更要紧。

截至 2026 年 10 月核对，Anthropic 的支持地区列表里**没有中国大陆、香港、澳门**，台湾在列。支持地区页面写明：未列出的国家和地区不受支持。

官网结账只接受信用卡和借记卡。国内的银联卡、支付宝用不了，国内发行的双币卡也经常被拒（card declined）。注册环节通常还要用能收验证码的手机号。

正规路径就两条：

**自己用海外卡在官网订阅。** 官方价，续费自动扣，账单、发票、取消都在 Settings → Billing 里管，最可控。门槛是得有一张能过验证的境外卡。

**外区 Apple ID 加当地礼品卡，在 iPhone App 内订阅。** 不需要信用卡，价格按当地 App Store 结算，续费和取消走苹果的订阅管理。步骤多，礼品卡要买对区，价格也未必比官网低。

代充平台不建议作为首选。账号处在非支持地区、多人共用、付款被撤销，都是账号被停用的常见原因，钱付了服务没了的情况并不少见。官方支持地区页面已经写明未列出的地区不受支持，这个风险得自己承担。

账号真被停用了，登录 claude.ai 后点左下角头像 → Get help 提交申诉，能否恢复、是否退款以官方处理结果为准。

## 订完之后容易踩的五个坑

**1. 钱充到了 Console，会员还是 Free**

console.anthropic.com 是 API 平台，充进去的是 API 额度，和 claude.ai 的会员订阅是两套账户。会员要在 claude.ai 的设置里升级。API 余额只会按 API 调用消耗，不会让聊天界面变成 Pro。

**2. 付了钱，右上角还显示 Free Plan**

按这个顺序排查：退出重新登录；换你可能注册过的其他邮箱或登录方式各试一次；去 Settings → Billing 看最近一次付款状态，失败就更新付款方式；确认当前不在 Team 空间里；手机上订阅的，电脑要登录同一个账号；最后刷新页面。

官方账单 FAQ 列的原因是登录邮箱和开通会员的邮箱不一致，或者付款失败导致账号降级。

**3. 有 Pro，Claude Code 却提示要充 API 或 Credit balance is too low**

两种可能：登录时选了 Anthropic Console 账号而不是订阅账号；或者环境变量里有 `ANTHROPIC_API_KEY`，官方说明这个变量的优先级高于订阅，即使有 Pro 也会按 API 扣费。

处理：在 Claude Code 里输入 `/login`，选 Claude 账号登录；然后 `unset ANTHROPIC_API_KEY`（Windows PowerShell 用 `Remove-Item Env:ANTHROPIC_API_KEY`），把 `~/.zshrc`、`~/.bashrc` 里的 export 行删掉，重开终端，用 `/status` 确认当前走的是订阅。官方还建议不想碰 API 账单就 `claude logout` 再 `claude login`，只用 Pro/Max 账号登录。

**4. 提示 “Due to unexpected capacity constraints”**

这是全体用户请求过多导致的临时情况，跟你的额度无关，也不算出故障。等几分钟重试即可。Claude Code 里对应的是 `529 Overloaded`，可以用 `/model` 换个模型继续。

**5. 登录报错 “There was an error logging you in”**

官方列出的常见原因是 VPN、浏览器扩展、缓存和 Cookie 干扰，也可能是服务端故障。关掉 VPN、禁用扩展、清缓存再试，仍然不行就看 status.claude.com 有没有故障公告。

## 取消：期末生效，提前 24 小时

Pro、Max、Ultra 都可以随时取消。取消在当前计费周期结束时生效，在此之前付费权益照常使用。

要避免下一期扣费，得在**下一个账单日前至少 24 小时**操作，不是点了取消就立刻失效。

路径按你当初订阅的地方走：

- **网页版或桌面端**：登录后点左下角头像或姓名 → Settings → Billing → Cancel。
- **iOS**：App 内右上角头像 → Billing → Manage subscription，或在 Apple 账户的订阅设置里取消。
- **Android**：App 内右上角头像 → Billing → Manage subscription，或在 Google Play 的订阅里取消。

Max、Ultra、Team 附带的每月 API credits 属于赠送，不能退款，每个计费周期末过期。取消或退款后不再发新的 credits，已有的可以用到过期为止。
